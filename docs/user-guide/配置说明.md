# 配置说明

EdgeLLM-Serving 启动时会读取配置文件（默认 `config.json`；可通过环境变量 `CONFIG_PATH` 指定其它路径）。

注意：配置里的相对路径（如 `models[*].model_path`）按“进程启动时的当前工作目录”解析；推荐在仓库根目录运行（或在配置里使用绝对路径）以避免找不到模型文件。

这份配置决定：

- HTTP 监听端口与限流/超时/队列上限
- 逻辑模型名如何映射到本地或 RPC 后端
- 默认后端（local / stackflow）
- 可选的 Redis session 持久化
- 默认关闭的实验能力开关（agent / rag）

## 1. 模型名与后端选择

推荐把请求里的 `model` 当成“逻辑模型名”，例如 `qwen3.5-2b`。

请求可以通过 `inference_backend` 做后端切换：

- `inference_backend=local` 表示本地 `llama.cpp`
- `inference_backend=rpc` / `remote` / `worker` / `stackflow` 表示远端 StackFlow worker

如果请求里不带 `inference_backend`，服务端会按模型条目（或全局 `serving_backend`）选择默认后端。

## 2. models 注册表（示例）

`models` 用于描述“逻辑模型名”对应的可用后端能力与模型路径（示例取自仓库默认 `config.json` 的写法风格）：

```json
{
  "default_model": "qwen3.5-2b",
  "models": {
    "qwen3.5-2b": {
      "default_backend": "local",
      "capabilities": ["chat", "embeddings", "rerank"],
      "backends": {
        "local": {
          "engine": "llama",
          "model_path": "models/qwen3.5/Qwen3.5-2B-Q4_K_M.gguf",
          "capabilities": ["chat", "embeddings", "rerank"]
        }
      }
    }
  }
}
```

模型列表接口 `/v1/models` 会暴露：

- `declared_backends`: 配置中为该逻辑模型声明的后端（模型级，内部命名：`local` / `stackflow`）
- `backends`: 网关侧可用后端（对外命名：`local` / `rpc`；其中 `rpc` 会在内部归一为 `stackflow`）
- `gateway_backends`: 网关支持的请求级后端切换（路由级，对外命名：`local` / `rpc`）

## 3. 主线关键配置（按主题）

服务与调度：

- `http_port`
- `worker_threads`
- `max_model_queue` / `max_session_pending` / `max_queue_wait_ms`
- `http_request_timeout_ms`
- `max_concurrent_requests` / `max_model_concurrency` / `max_session_concurrency`

本地 llama：

- `llama_model_path`
- `llama_n_ctx` / `llama_n_threads` / `llama_n_threads_batch`
- `kv_reset_margin`
- `default_max_tokens`

远程 stackflow（RPC）：

- `serving_backend`（`local` 或 `stackflow`）
- `stackflow_host` / `stackflow_port` / `stackflow_unit`
- `stackflow_timeout_ms` / `stackflow_infer_timeout_ms`
- `stackflow_reuse_work_id` / `stackflow_serialize_reuse`
- `stackflow_max_concurrency`

可选：Redis session 持久化：

- `session_persist_redis`
- `redis_host` / `redis_port` / `redis_db`
- `session_redis_prefix` / `session_redis_ttl_seconds` / `redis_timeout_ms`

## 4. 实验能力开关（默认关闭）

这两项默认是 `0`，用于控制兼容接口是否开放：

- `experimental_agent_api_enabled` 对应环境变量 `EXPERIMENTAL_AGENT_API_ENABLED`
- `experimental_rag_api_enabled` 对应环境变量 `EXPERIMENTAL_RAG_API_ENABLED`

实验能力文档统一放在：

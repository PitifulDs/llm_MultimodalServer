# 快速开始

本文档只解决三件事：编译、启动、验证。更完整的配置与接口细节见本目录其它文档。

## 1. 本地推理（llama.cpp）

Build:

```bash
cmake -S . -B build
cmake --build build -j
```

Run（在仓库根目录运行，确保相对路径生效）:

```bash
./build/serving/http/serving_http_server
```

Verify:

```bash
curl -s "http://127.0.0.1:8080/healthz" | jq
curl -s "http://127.0.0.1:8080/v1/models" | jq
```

Chat（非流式）:

```bash
curl -s -X POST "http://127.0.0.1:8080/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d "{\"model\":\"qwen3.5-2b\",\"messages\":[{\"role\":\"user\",\"content\":\"hello\"}]}" | jq
```

Chat（流式 SSE）:

```bash
curl -sS -N -X POST "http://127.0.0.1:8080/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d "{\"model\":\"qwen3.5-2b\",\"stream\":true,\"messages\":[{\"role\":\"user\",\"content\":\"hello\"}]}"
```

主线自检（smoke）:

```bash
bash scripts/smoke_test.sh
```

配置说明见：[`配置说明.md`](配置说明.md)。

## 2. 远程推理（StackFlow / RPC）

远程模式由三段进程组成：`unit-manager` + worker（`node/test` demo）+ HTTP server。

启动顺序（示例）:

1. `unit-manager`

```bash
./unit-manager/build/unit_manager
```

2. worker（`node/test`）

```bash
./node/test/build/test
```

3. HTTP server

```bash
./build/serving/http/serving_http_server
```

一键脚本:

```bash
bash scripts/start_all.sh
```

日志目录:

- `/tmp/llm_serving`

清理旧 socket（排障常用）:

```bash
rm -f /tmp/llm/*.sock*
```

常见排障入口见：[`可观测性与排障.md`](可观测性与排障.md)。

## 4. 常用环境变量（测试脚本 / 启动）

smoke_test：

```bash
BASE_URL=http://127.0.0.1:8080 MODEL=llama bash scripts/smoke_test.sh
```

HTTP server（可选）：

```bash
# 指定配置文件路径（默认读取 ./config.json）
CONFIG_PATH=/abs/path/to/config.json ./build/serving/http/serving_http_server

# 覆盖端口：环境变量或 argv（二者都支持）
HTTP_PORT=8090 ./build/serving/http/serving_http_server
./build/serving/http/serving_http_server 8090

# 跳过启动 warmup（冷启动更快，适合调试）
WARMUP_MODEL=0 ./build/serving/http/serving_http_server
```

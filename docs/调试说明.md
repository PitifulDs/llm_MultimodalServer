# 调试说明

本文档只描述当前稳定可调试的 agent 能力和验证入口。

## 1. 对外模式边界

- `code_analysis`
  主推模式。只读、证据优先，优先仓库、本地文档、配置和运行时证据。

- `web_research`
  增强模式。用于外部资料交叉验证，额外开放受控 `search_web / fetch_url`。

- `generic`
  保留内部实验用途，不作为公开调试模式。

## 2. 调试接口

公开调试入口：

- `POST /v1/agent/debug`

当前返回的核心字段：

- `planner_steps`
- `evidence`
- `final_answer`
- `content`
- `references`

`code_analysis` 示例：

```bash
curl -s -X POST "http://127.0.0.1:8080/v1/agent/debug" \
  -H "Content-Type: application/json" \
  -d '{
    "model":"llama",
    "mode":"code_analysis",
    "debug":true,
    "query":"references 是在哪里拼出来的"
  }' | jq
```

`web_research` 示例：

```bash
curl -s -X POST "http://127.0.0.1:8080/v1/agent/debug" \
  -H "Content-Type: application/json" \
  -d '{
    "model":"llama",
    "mode":"web_research",
    "debug":true,
    "tools":["search_kb","open_chunk","search_code","read_file","search_docs","search_web","fetch_url"],
    "query":"结合仓库和 http://example.com/ 页面，说明 web_research 的 references 是否会保留外部 URL。"
  }' | jq
```

## 3. Smoke Test

```bash
bash scripts/smoke_test_agent_code_analysis.sh
bash scripts/smoke_test_agent_web_research.sh
```

当前覆盖：

- `code_analysis`: `search_kb -> open_chunk`、`search_code -> read_file`、structured output、debug trace
- `web_research`: `search_web -> fetch_url -> synthesis`

## 4. Eval

```bash
python3 tools/agent/eval_code_analysis.py --base-url http://127.0.0.1:8080 --model llama
python3 tools/agent/eval_code_analysis.py --mode web_research --base-url http://127.0.0.1:8080 --model llama
```

当前数据集：

- `tools/agent/eval_dataset.jsonl`
  仓库内问答与本地证据定位。

- `tools/agent/eval_dataset_web_research.jsonl`
  外部资料交叉验证样本，要求同时出现 repo/local 与 web 侧证据。

## 5. 当前冻结范围

当前优先做稳定性修正，不继续扩展新工具、新模式或新的 planner 分支。

当前允许继续迭代的范围：

- bug
- trace
- references
- 返回格式
- 评测
- 文档

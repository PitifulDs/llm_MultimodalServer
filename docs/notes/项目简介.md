# 项目简介（去掉 agent 版）

EdgeLLM-Serving 是一个轻量的 LLM Serving / Model API 平台：对外提供 OpenAI 兼容 HTTP/SSE 接口，对内统一封装本地 `llama.cpp` 推理与远程 `stackflow`（RPC）推理。

你可以把它理解为三层：

- 协议层：HTTP 组包、参数校验、错误码映射、SSE 流式回写（`/v1/chat/completions`、`/v1/embeddings`、`/v1/rerank`）
- 调度层：同 session 串行 + 按 capability/model/backend 排队 + 背压与超时兜底
- 引擎层：本地引擎（GGUF）与远程引擎（setup/inference/exit）的统一抽象与切换

配套能力：

- 模型目录与状态：`/v1/models`、`/admin/*/status`
- 治理口径：并发限制、队列上限、等待超时、取消与统一统计
- 运维脚本与日志：一键启动/停止、统一日志目录，便于复现与排障
